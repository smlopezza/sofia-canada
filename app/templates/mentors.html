{% if lang == 'es' %}Cómo prepararte para aprovechar al máximo la conversación {% else %}How to make the most of your conversation{% endif %}

{% if lang == 'es' %}Estos mentores están dando su tiempo voluntariamente. Llegar preparado es la mejor forma de agradecérselos. {% else %}These mentors are giving their time voluntarily. Coming prepared is the best way to honor that.{% endif %}

  • {% if lang == 'es' %}📋 Investiga antes{% else %}📋 Do your research first{% endif %}
    {% if lang == 'es' %}Revisa su LinkedIn. Conoce su industria y trayectoria antes de escribirles.{% else %}Check their LinkedIn. Know their industry and background before reaching out.{% endif %}
  • {% if lang == 'es' %}✉️ Escribe con claridad{% else %}✉️ Reach out clearly{% endif %}
    {% if lang == 'es' %}Preséntate en una o dos frases: quién eres, en qué momento de tu transición estás y qué esperas aprender de ellos. Cuéntales que encontraste su perfil en SofIA, les da contexto y les recuerda que eligieron estar aquí.{% else %}Introduce yourself in one or two sentences: who you are, where you are in your transition, and what you're hoping to learn from them. Let them know you found their profile on SofIA, it gives them context and reminds them they chose to be here.{% endif %}
  • {% if lang == 'es' %}⏱️ Respeta los 30 minutos{% else %}⏱️ Respect the 30 minutes{% endif %}
    {% if lang == 'es' %}Llega puntual y termina a tiempo. Si el mentor quiere seguir, él o ella lo dirá.{% else %}Arrive on time and wrap up on time. If they want to continue, they'll say so.{% endif %}
  • {% if lang == 'es' %}🎯 Ten preguntas específicas{% else %}🎯 Come with specific questions{% endif %}
    {% if lang == 'es' %}Prepara 2 o 3 preguntas concretas. Las conversaciones vagas no aprovechan el tiempo de nadie.{% else %}Prepare 2–3 concrete questions. Vague conversations don't serve anyone's time well.{% endif %}
  • {% if lang == 'es' %}🤝 No pidas empleo en el primer contacto{% else %}🤝 Don't ask for a job referral first time{% endif %}
    {% if lang == 'es' %}El objetivo es aprender y construir una relación genuina. Las oportunidades llegan cuando hay confianza.{% else %}The goal is to learn and build a genuine relationship. Opportunities come with trust.{% endif %}
  • {% if lang == 'es' %}💌 Agradece siempre{% else %}💌 Always follow up with thanks{% endif %}
    {% if lang == 'es' %}Envía un mensaje de agradecimiento después. Cuéntales qué fue lo más útil. Les importa saber que ayudaron.{% else %}Send a thank-you message after. Tell them what was most useful. They care to know they helped.{% endif %}
