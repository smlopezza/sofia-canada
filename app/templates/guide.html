{% if lang == 'es' %} El objetivo de SofIA es hacerse innecesaria. {% if lang == 'es' %}Lo que SofIA no hace{% else %}What SofIA doesn't do{% endif %}

{% if lang == 'es' %} SofIA está enfocada en una cosa: ayudarte a construir conexiones profesionales reales. Para todo lo demás, hay personas y recursos mejor preparados. {% else %} SofIA is focused on one thing: helping you build real professional connections. For everything below, there are better-suited people and resources. {% endif %}

  • {% if lang == 'es' %}❌ Revisar tu CV o carta de presentación{% else %}❌ Resume or cover letter review{% endif %}
    {% if lang == 'es' %} Para eso, organizaciones de asentamiento (ACCES Employment, COSTI), coaches de carrera, o los servicios de tu college son el lugar indicado. {% else %} For that, settlement organizations (ACCES Employment, COSTI), career coaches, or your college's career services are the right place. {% endif %}
  • {% if lang == 'es' %}❌ Reemplazar a un mentor o coach de carrera{% else %}❌ Replace a mentor or career coach{% endif %}
    {% if lang == 'es' %} SofIA es una aliada — te ayuda a prepararte y reflexionar, pero no reemplaza a una persona real que te conozca, te abra puertas, y te dé retroalimentación de fondo. {% else %} SofIA is an ally — she helps you prepare and reflect, but she doesn't replace a real person who knows you, opens doors for you, and gives you deep feedback. {% endif %}
  • {% if lang == 'es' %}❌ Notas de voz{% else %}❌ Voice notes{% endif %}
    {% if lang == 'es' %} Por ahora solo lee texto. Si tienes algo que decir, escríbelo aunque sea corto. {% else %} For now she only reads text. If you have something to say, just type it, even if it's short. {% endif %}
  • {% if lang == 'es' %}❌ Preguntas de inmigración{% else %}❌ Immigration questions{% endif %}
    {% if lang == 'es' %} Para visas, permisos de trabajo, o estatus migratorio, la fuente correcta es el gobierno de Canadá (canada.ca/immigration) o un consultor de inmigración certificado (ICCRC). {% else %} For visas, work permits, or immigration status, the right source is the Government of Canada (canada.ca/immigration) or a certified immigration consultant (ICCRC). {% endif %}
  • {% if lang == 'es' %}❌ Apoyo de salud mental{% else %}❌ Mental health support{% endif %}
    {% if lang == 'es' %} SofIA puede escucharte y orientarte, pero no es terapeuta ni trabajadora social. Si estás pasando por algo difícil, marca el 211 para conectar con servicios gratuitos en tu ciudad, o llama al 988 si estás en crisis. {% else %} SofIA can listen and point you in the right direction, but she's not a therapist or social worker. If you're going through something hard, call 211 to connect with free services in your city, or call 988 if you're in crisis. {% endif %}
